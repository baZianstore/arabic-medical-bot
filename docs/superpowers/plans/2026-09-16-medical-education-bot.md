# خطة تنفيذ بوت التعليم الطبي

> **للعامل البرمجي:** نفّذ الخطوات بالترتيب مع اختبار كل وحدة قبل الانتقال.

**الهدف:** إنشاء بوت تيليغرام عربي ولوحة إدارة Supabase آمنة وقابلة للنشر.

**البنية:** خدمة Python واحدة تشغّل Flask وpython-telegram-bot. يعمل محليًا بالاقتراع الطويل، ويعمل على الاستضافة عبر webhook. طبقة Supabase مستقلة، وجدولة يومية داخلية مع منبّه HTTP خارجي اختياري للخطة المجانية.

**المكدس:** Python 3.10+، Flask، python-telegram-bot، Supabase، APScheduler، pytest، Bootstrap RTL.

**المواصفة:** `SPEC.md`

## القيود العامة

- كل النصوص الظاهرة عربية.
- لا بيانات مرضى أو PHI.
- الأسرار في متغيرات البيئة فقط.
- جلسة الإدارة Cookie `HttpOnly`، ولا Web Storage.
- الدور الافتراضي مرفوض، ودور الإدارة الوحيد صريح.
- بيانات الاختبار اصطناعية.
