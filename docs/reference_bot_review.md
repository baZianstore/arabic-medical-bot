# مراجعة البوت المرجعي @bizzo26_bot

**الرابط العام:** https://t.me/bizzo26_bot
**تاريخ الفحص:** 2026-09-17

تُظهر صفحة Telegram العامة فقط الوصف التالي: «فهرس طبي عربي: ملخصات، أسئلة، صور ومراجع موثوقة.» ولا تكشف الصفحة العامة تدفق المحادثة أو المحتوى الداخلي من دون بدء البوت داخل حساب Telegram.

## قرار المنتج

يُستخدم المرجع لإلهام فئات الوظائف فقط، لا لنسخ النصوص أو الصور أو الأسئلة. النسخة الجديدة في `@Intmed_edu_bot` ستقدم محتوى أصليًا: نصًا طبيًا إنجليزيًا يتبعه شرح عربي، وأسئلة إنجليزية مع تفسير عربي، ومراجع رسمية مباشرة، وصور تعليمية أصلية، وقائمة أزرار داخلية.

## حدود الأمان

المحتوى تعليمي عام فقط. لا توجد بيانات مرضى أو تشخيص شخصي أو جرعات علاجية فردية. لا تُسجل رسائل المستخدمين، ولا تُرسل أي بيانات صحية شخصية إلى خدمات خارجية.
