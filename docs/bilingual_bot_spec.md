# مواصفة البوت الطبي ثنائي اللغة

> `SECURITY-GATE: healthcare-app-security-guardrails loaded — phase=design — status=ENFORCED`

## الهدف

تطوير `@Intmed_edu_bot` إلى تجربة تعليمية أصلية مستوحاة وظيفيًا من تصنيفات البوت المرجعي `@bizzo26_bot` دون نسخ نصوصه أو صوره. تعرض النسخة الجديدة **المعلومة الطبية بالإنجليزية ثم تشرحها بالعربية**، وتجمع الملخصات والأسئلة والصور والمراجع الرسمية في قائمة تفاعلية سهلة.

## افتراضات التنفيذ

1. يُطوّر البوت الحالي بدل إنشاء توكن أو بوت ثانٍ.
2. النمط الافتراضي ثنائي اللغة دائمًا؛ لا نحتاج تخزين تفضيل لغة المستخدم.
3. المحتوى الأولي يغطي الأمراض الخمسة الموجودة في Supabase، ويعود البوت تلقائيًا إلى العرض العربي لأي مرض جديد لم تُضف له بطاقة ثنائية بعد.
4. الصور تعليمية أصلية وغير تشخيصية، ولا تحتوي بيانات أشخاص.

## القدرات

| الوحدة | المسؤولية | معيار القبول |
|---|---|---|
| القائمة | أزرار للوصول إلى موضوع اليوم والاختبار والمصادر والإحصاءات | تعمل من `/start` و`/menu` |
| الموضوع الثنائي | ملخص إنجليزي، شرح عربي، نقاط أساسية، تشخيص، تدبير، إنذارات، ولؤلؤة سريرية | رسالة آمنة ضمن حدود Telegram |
| الاختبار الإنجليزي | سؤال وأربعة خيارات بالإنجليزية مع شرح عربي بعد الإجابة | يعطل الأزرار بعد الإجابة ويعرض التصحيح |
| الصور | صورة أصلية لكل واحد من الأمراض الخمسة | تُرسل قبل البطاقة النصية، مع fallback نصي عند فشل الصورة |
| المراجع | 2–3 روابط رسمية مباشرة لكل موضوع | لا توجد روابط تجارية أو محتوى منسوخ |
| التوافق | استمرار `/today` و`/search` و`/quiz` و`/systems` و`/stats` | الاختبارات الحالية تبقى ناجحة |

## الأوامر

- `/start` و`/menu`: قائمة البداية.
- `/today`: موضوع اليوم بالإنجليزية مع شرح عربي وصورة.
- `/learn [اسم]`: بطاقة موضوع محدد بالعربية أو الإنجليزية.
- `/quiz_en`: سؤال إنجليزي وشرح الإجابة بالعربية.
- `/sources [اسم]`: مراجع موضوع محدد، أو موضوع اليوم عند غياب الاسم.
- الأوامر العربية الحالية تبقى كما هي.

## مسار البيانات والأمان

المحتوى الطبي العام يُقرأ من Supabase، وتُكمّله بطاقات تعليمية ثابتة مراجعة في الخادم. لا يرسل المستخدم بيانات سريرية، ولا يحلل البوت أعراضًا شخصية، ولا تُحفظ نصوص البحث. لا يوجد PHI في الشبكة أو السجلات أو الصور. لا تتغير مصادقة لوحة الإدارة ولا صلاحياتها.

| الدور | المورد | الفعل | النطاق | السماح | المنع الصريح | موضع الإنفاذ |
|---|---|---|---|---|---|---|
| مستخدم Telegram | محتوى عام | قراءة/اختبار | عالمي | أوامر معروفة وcallback صالح | لا تعديل ولا إدارة ولا تحليل حالة شخصية | معالجات Telegram |
| مشرف | الأمراض والأسئلة | CRUD | عالمي | جلسة خادم موثقة + CSRF | مجهول الهوية أو جلسة منتهية | Flask routes |
| حساب الخدمة | Supabase | CRUD | جداول التطبيق فقط | مفتاح خادمي في Render | `anon` و`authenticated` مرفوضان | RLS وgrants |

## الاختبار

تشغيل `pytest -q` و`ruff check` و`compileall`. تُختبر سلامة HTML، حدود طول الرسائل، callback غير صالح، وجود اللغتين، صحة قائمة الأوامر، وغياب الأسرار وحقول المرضى. يُجرى smoke test إنتاجي على `/start` و`/today` و`/quiz_en` بعد النشر.

## حدود النطاق

- لا تشخيص شخصي، لا وصفات أو جرعات، ولا استقبال ملفات مرضى.
- لا نسخ من البوت المرجعي.
- لا إنشاء محتوى تلقائي بالذكاء الاصطناعي وقت الطلب؛ المحتوى يراجع قبل النشر.
